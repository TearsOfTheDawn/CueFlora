## Prepared release-note text

CueFlora adds source subtitles and translations to YouTube, with custom appearance, optional word highlighting/Chinese pinyin, and AI services you choose. AI starts only after Run. The on-demand Windows helper bundles Python and audio tools; separate Python installation, administrator access and PATH edits are not required. Models and AI credits are not provided: users supply compatible services and any required API access.

Windows x64 / Google Chrome is the intended release target. The first installer is unsigned. Do not disable Windows/security protection; stop if a file/hash or publisher does not match expectations. Source, original third-party notices, corresponding sources and build instructions accompany this release. Checksums identify bytes, not publisher authenticity or harmlessness.

Install the Store extension when available → run the matching Setup, explicitly select Chrome and Install → connect existing compatible transcription/translation APIs → choose languages → open the flower button and press Run. Provider fees/retention and recognition/translation errors remain outside CueFlora's control. Metadata success is not generation compatibility.

Setup provides Repair, Roll back and recoverable Uninstall. Uninstall removes owned registration/shortcut entries and quarantines runtime files while preserving settings/evidence. Preview/Store identities cannot silently take each other over. Do not modify Substrata.

The 0.1.12 changes add original V8 submodule notices, complete Cargo source delivery, labelled attribution records, explicit third-party terms and frozen solver environment hardening. All 28 automated preparation checks passed. Two native symlink-permission tests were skipped on the build environment. Real-browser/clean-machine functionality is deferred, not claimed tested; other platforms are uncertified. Native advisories have scoped engineering assessments, not all upstream patches or a universal security certificate.
