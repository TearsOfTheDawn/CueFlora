Detailed description:

CueFlora displays source subtitles and translations together on YouTube. Use captions available on the video, or connect compatible AI services you choose for transcription and translation. AI generation starts only when you press Run.

Make subtitles comfortable to read with separate source/translation styling, size, background, position and appearance presets. Optional word highlighting and Chinese pinyin support language learning. No provider, service address or model is preselected.

AI transcription requires the separate CueFlora helper for Windows x64. After Run, the helper temporarily downloads the selected video's audio, prepares it and sends audio chunks to your chosen transcription service. Translation sends subtitle text, languages, neighbouring context and limited video title/description context to your chosen translation service. Use is subject to applicable content and service permissions.

The helper includes Python and its audio tools, runs on demand and needs no administrator installation or PATH editing. Its bundled downloader may retrieve YouTube player JavaScript and evaluate challenge code in a separate native Deno process. Remote solver component downloads are disabled. CueFlora is not a media-export or offline-playback application.

Bring your own compatible services and any required API access. Transcription uses a Whisper-compatible audio/transcriptions endpoint. Translation uses a chat/completions endpoint with structured JSON output. Transcription and translation can use different services. Local services must already be running; CueFlora does not install models, start servers or include AI credits. Provider pricing, availability, retention and terms apply independently. A website subscription or ChatGPT login is not necessarily API access.

Settings guide you through connecting the helper, connecting AI, and choosing languages. Services without model listing can use manual model entry. Connection checks request metadata only and do not guarantee subtitle-generation compatibility. AI setup may be postponed; caption-only use needs no helper when suitable captions are available.

Remembered API keys use Windows user-scoped encryption. No publisher analytics or inference server is included. Speech recognition and translation can be inaccurate. Windows/Chrome is the intended first supported release; other platforms are not certified. The first helper installer is unsigned and Windows/security software may warn; do not disable your protection.
