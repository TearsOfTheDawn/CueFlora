1. Connect the helper

The helper downloads and prepares audio and connects to your chosen AI services. It runs only when needed.

Run CueFlora Setup.exe from the preview package, select Chrome, then Install. Python and audio tools are included. Substrata is a separate installation.

How to repair

Open CueFlora Setup from the Start Menu or the downloaded installer and choose Repair. This does not configure AI or change browser/provider settings.

2. Connect your AI services

Choose hosted or existing local services independently for each stage. Neither is preselected. Hosted providers may charge for API use; local services must already be running.

Transcription needs a compatible /audio/transcriptions API. Translation needs /chat/completions with structured JSON output. Ollama alone is not a transcription service.

For each stage, enter your service's API address, optional access key and exact model ID. Save explicitly; active Runs keep their current settings.

Saved keys and privacy

Keys use Windows user protection and are sent only to the configured service. Existing saved keys are never displayed. A migration warning means an older key still needs protection. This does not defend against malware running as your Windows user.

What information do I need?

Ask your service provider or local-service administrator for its API base address, the exact model name, and an API key if authentication is required. A website login or subscription is not necessarily API access. CueFlora does not choose a provider, buy API access, install models, or start local services.

Model discovery is optional and checks metadata only. If it is unavailable, you can still enter the model name yourself. Only Run on YouTube requests transcription or translation.

Save AI settings before continuing. You can leave either stage unconfigured and use available YouTube captions instead.

3. Choose your languages

Your caption/AI selections are preserved when you revisit setup. YouTube captions depend on the video and may not exist in your chosen language; CueFlora never silently replaces them with AI. On YouTube, open the flower button to change selections or Appearance. Only Run generates AI subtitles.
