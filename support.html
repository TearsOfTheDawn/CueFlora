CueFlora support

Use CueFlora GitHub Issues. No public support email is required. Issue reports and replies are public; they must not contain credentials, encrypted credential payloads or private captures. Source/help publication does not mean the installer or Store extension has been released.

No subtitles: check source/language selections in the flower panel and press Run for AI generation. Native captions depend on the video/language.

Helper unavailable: use the matching CueFlora Setup, select Install or Repair, then Check helper connection. Do not repair Substrata or a differently bound preview. Helper connectivity does not prove AI compatibility.

Service errors: verify the API base address, optional key and exact model name. Website login/subscription is not necessarily API access. Model discovery can be unsupported; manual entry remains available. CueFlora installs or starts no AI services.

Reports should contain app/Windows/Chrome versions, the failing step and redacted reason codes. Never post keys, encrypted credential records, signed media URLs or private captures. Share video/text only with permission and awareness of its contents.

Setup offers Repair, Roll back and Uninstall. Uninstall unregisters owned entries and quarantines runtimes; retained settings/evidence need a separate explicit removal choice.
