CueFlora support

Use GitHub Issues. Reports and replies are public: never post API keys, encrypted credential payloads, signed media URLs or private captures.

Chrome Store publication is no longer planned. No Store account action or screenshot is requested. See the current GitHub installation route; the matching public installer is not available yet.

Existing private previews

Use the unpacked extension and Setup from the same package. Their extension/native-host identities must match. Do not load a keyless submission ZIP in place of the supplied preview.

Open settings and use the explicit helper check. A connected helper may still need Repair/Upgrade if tools or credential protection are missing. Model discovery checks metadata only; compatible transcription/chat-completions services must already be available. No provider, model, API key or ChatGPT-account access is supplied.

Remembered keys use Windows user-scoped protection, which does not protect against malware running as the same user. AI output may be inaccurate and hosted inference may cost money. Local AI services are not installed or started by CueFlora.

Setup retains repair, rollback and recoverable uninstall. Uninstall removes owned registration and quarantines runtimes; browser settings/evidence remain. Never remove Substrata to repair CueFlora.

Report app/Windows/Chrome versions, the failing step and redacted reason codes. Do not claim an old package was rebuilt by a source or documentation update.

Permission is separate from hosting

No general YouTube permission has been established for CueFlora’s current automatic audio-download method. Changing to GitHub does not grant that permission or prove that every use or software distribution is illegal. The app and its native downloading behavior are not being disguised or changed.
