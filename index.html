CueFlora

AI Subtitles & Translation for YouTube.

Not released yet: the source and privacy/help pages are available for review, but no public installer or Chrome Store extension is offered here.

CueFlora combines available YouTube captions with optional transcription and translation using services you choose. AI generation starts only when you press Run. No provider or model is preselected.

Release status and intended installation

Windows x64 / Chrome is the intended first release. Other platforms are not certified. Model output can be wrong.
