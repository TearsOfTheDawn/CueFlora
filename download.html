GitHub installation and release status

No public CueFlora installer is published yet. Do not use an unrelated helper, a keyless Store-submission ZIP or an old package expecting it to have changed.

Intended installation after release

  1. Download the matching extension/helper package from GitHub Releases and extract it to a permanent folder.
  2. Open chrome://extensions, enable Developer mode, choose Load unpacked and select the included extension folder containing manifest.json.
  3. Run the matching CueFlora Setup.exe, explicitly select Chrome and confirm installation.
  4. Connect existing compatible AI services, choose languages and press Run on YouTube. Suitable captions can be used without AI setup.

This is manual developer-mode loading, not an automatic consumer extension installation. Keep the extracted folder. Extension updates require replacing files with the same identity and reloading; helper updates use Setup. The helper bundles Python/audio tools, runs only on demand and does not install models or start AI services.
