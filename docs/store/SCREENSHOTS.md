# Genuine screenshot checklist (deferred)

Promotional PNG/SVG assets are brand graphics, not evidence of a working browser session. Do not manufacture a YouTube screenshot or include fake generated subtitles as a live result.

Later capture with consent and permission for the displayed video/text:

1. Normal Chrome YouTube view with the flower button and genuine source/translation subtitles.
2. Appearance controls and their real preview, without changing approved layout.
3. Setup helper check showing the actual version/four-tool result.
4. Provider-neutral AI setup with all addresses, keys and private model details hidden/redacted.
5. Language selection and explicit Run/status, demonstrating no automatic inference.

The reviewed official page specifies at least one 1280×800 screenshot, up to five; confirm the dashboard at submission rather than stretching/cropping the UI misleadingly. Promotional drafts use 440×280 and 1400×560, with a 128×128 icon already supplied. Check legibility and truthful content visually before uploading.
