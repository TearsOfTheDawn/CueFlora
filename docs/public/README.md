# Public source/privacy/help pages

The publisher authorized source and privacy/help publication on 2026-10-15, separately from the unreleased installer and Store item. Use `packaging/public_materials.py --prelaunch` with the verified publisher/Store identity and chosen GitHub Issues support. It emits a buildless kit with `.nojekyll`, a clear pre-release banner and no executable, ZIP or Store download links. Generation is not deployment.

The Pages publishing branch is `codex/public-pages`, folder `/ (root)`. See [source/Pages preparation](../PUBLIC_SOURCE_AND_PAGES.md) for the account settings and expected addresses. Do not call those addresses live until deployment and HTTPS content are verified. Public release approvals, licence/policy clearance and final installer binding remain separate.
