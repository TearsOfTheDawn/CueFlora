**Only download `CueFlora-0.1.13-Windows-x64.zip`.** It includes both the Chrome extension and Setup. You do not need any of the other files under Assets for normal installation.

### Install in five steps

1. **Extract** the ZIP to a permanent folder.
2. **Add the extension:** open `chrome://extensions`, enable **Developer mode**, click **Load unpacked**, and select `CueFlora Setup/Chrome-extension` inside the extracted folder. Keep this folder.
3. **Install the helper:** run **CueFlora Setup.exe** in the extracted `CueFlora Setup` folder. Select **Chrome**, read Third-party terms and confirm **Install**.
4. **Connect your AI services:** open CueFlora settings, check the helper connection, enter your existing service details, save, and choose languages.
5. **Use it:** open a YouTube video, click the **flower button**, then **Run**.

Windows x64 / Google Chrome. No separate Python installation, administrator access or PATH changes are needed. AI services/models are not included; compatible transcription and translation APIs are required for AI generation. Available YouTube captions can be used without AI configuration.

The installer is **unsigned**. Do not disable security software. Hosted AI can cost money, and subtitles can be inaccurate.
